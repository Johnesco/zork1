Zork I: The Great Underground Empire

Inform 7 Edition

I first played Zork on an Atari 800. I was too young to get very far — the game was a mystery that lay hidden behind puzzles too twisty for little kid me to figure out. But it stuck with me. The darkness, the mailbox, the feeling that there was something enormous just out of reach.

Decades later, Activision released the original source code under the MIT License. For the first time, I could read the code behind the curtain. And it felt like I could finally try making it my own — translating the game from its original ZIL into Inform 7, the modern natural-language interactive fiction system, and seeing how far I could take it.

Each version builds on the last. v0 is the original ZIL compiled and playable exactly as Infocom shipped it. v1 is the initial faithful translation into Inform 7 — every room, puzzle, and mechanic reproduced, bugs and all. v2 fixes those bugs. v3 begins exploring enhancements, starting with ambient sound. And v4, when it arrives, will be an attempt to reduce guess-the-verb stress by using AI to fill in far more synonyms and multiple phrasings than is normally put into your average interactive fiction.

v1 — First Light

Complete ZIL-to-Inform 7 translation of Zork I.

  • 110+ rooms across five regions: forest and house, cellar and troll area, maze, dam and river, coal mine
  • All 19 treasures with trophy case scoring (350 points max) and ranked titles
  • NPCs: roaming Thief with combat and treasure redistribution, Troll combat, Cyclops with multiple solutions
  • Full puzzle systems: dam and reservoir, exorcism ceremony, coal-to-diamond machine, inflatable boat and river, mirror rooms
  • Lamp timer (400 turns), candle timer (40 turns), match system (6 matches, 2-turn burn)
  • Death and resurrection system, grue darkness mechanic, sword glow proximity warning
  • Verbosity modes, score ranks, and diagnostic commands
  • Text: 300+ missing player responses restored from ZIL source — verb defaults, object-specific messages, scenery interactions, and random text tables (#44)
  • Dead player ghost state — explore as spirit with dimly-lit rooms, prayer resurrection at temple, ZIL-faithful action restrictions (#45)
  • Room descriptions enriched to match ZIL — Hades inscription, machine room, grating states, torch/dome details, Aragain Falls rainbow, mirror breakage; object fixes for painting, lantern, matchbook, torch (#46)
  • Object interaction responses — sceptre/rainbow, egg, skeleton, bubble, barrow door, maze diodes, machine bare-hands check, kitchen window, rug, large bag, rusty knife, chalice (#47)
  • Generic verb handlers — ZIL random text tables (YUKS, DUMMY, JUMPLOSS, HO-HUM), cut-with, destroy/mung, leap-over, overboard, disembark, inflate-with, push juggler, slide-to-cellar, throw “Thrown.”, fatal jump deaths, Dome Room conditional jump (#48)
  • Fix leaves/grate interaction — moving, taking, burning, cutting leaves now reveals grate; look-under gives temporary peek; burn-while-carrying is fatal (#50)
  • Missing object interactions — sword examine-while-glowing, trap door look-under, grate lock/unlock/pick/put-through, chalice insert, large bag unconscious-thief text, river float-vs-splash, bottle shake-spills-water, bag-of-coins/trunk close and insert handlers (#51)
  • Scenery objects and remaining text — boarded windows, chimney in Studio, Hades gate, mountain range, climbable cliff, skeleton kick/kiss, bat Fweep, candles count/insert-safety, dam plug variants, tool chest insert, hot bell ring-with-burnable, putty lubricant rejection, forest disembark, Canyon View death text (#52)
  • ZIL text accuracy — mirror examine/take/rub-with-object, thief description with stiletto, bodies guardian-of-dungeon death, basket “securely fastened”, cyclops 6-level agitation, match examine-when-lit, Gas Room deliberate-vs-accidental lighting variants, water leaks from non-bottle containers, V-PLAY actor death, V-FIND hands/lungs, exorcism equipment check, V-ALARM rudely-awakened, global hands/lungs backdrops (#53)

v0 — The Original ZIL

The unmodified Infocom ZIL source code, exactly as released by Activision under the MIT License. Includes a ZIL source browser with syntax highlighting and annotations, and a playable version of the game compiled directly from this source.

  • 10 ZIL source files (~12,000 lines) with navigable definitions
  • Annotation toggle explaining game engine and puzzle mechanics
  • Playable game compiled from the original ZIL using ZILF, the open-source ZIL compiler, producing a Z-machine story file (.z3)
  • Runs in-browser via Parchment, a JavaScript Z-machine interpreter — no downloads required
